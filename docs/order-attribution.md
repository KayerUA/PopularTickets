# Источники заказов

Перед публикацией приложения выполните `supabase/add-order-attribution.sql` в рабочей базе. Миграция добавляет nullable JSONB-колонку `orders.attribution`; старые заказы остаются с `null`.

При создании заказа checkout сохраняет первый переход (`first_touch`) и последний переход с известным источником (`last_non_direct_touch`). Каждая запись содержит источник, medium, пять UTM-параметров, время, путь страницы входа, origin внешнего referrer и `fbclid`, если он передан в ссылке. Query-параметры страниц и referrer целиком не сохраняются. Пути оценки и чека обрезаются, чтобы не сохранять токены доступа.

История хранится в браузере 30 дней. Внутренние переходы и возвраты напрямую сохраняют предыдущий известный источник. Без доступного localStorage данные текущего документа сохраняются в памяти до ухода на оплату. Без JavaScript данные источника не передаются, заказ сохраняет `null`. Метки, переданные с popularpoet.pl существующим механизмом ссылок, также попадают в заказ.

Страницы checkout, оценки, выбора мест, admin и API не создают новые переходы. Referrer Przelewy24 игнорируется, чтобы платёжный шлюз не заменял источник следующей покупки.

`source = 'direct'` означает отсутствие метки и доступного внешнего referrer, а не доказанный ввод адреса вручную. `source = 'meta'` означает `fbclid` без более точного источника; это не подтверждение платной рекламы Instagram. `source = 'unknown'` используется для UTM без utm_source и без другого доступного источника. Метки сообщает браузер, они не доказывают причинное влияние рекламы.

Источник фиксируется в pending-заказе до регистрации платежа. Последующие обновления статуса оплаты не меняют attribution. Для отчёта о продажах используйте `status = 'paid'`, положительную сумму и отдельно считайте заказы, билеты и выручку:

```sql
select
  coalesce(
    attribution -> 'last_non_direct_touch' ->> 'source',
    attribution -> 'first_touch' ->> 'source',
    'untracked'
  ) as source,
  count(*) as paid_orders,
  sum(quantity) as paid_tickets,
  sum(amount_grosze) / 100.0 as revenue_pln
from public.orders
where status = 'paid' and amount_grosze > 0
group by 1
order by revenue_pln desc;
```

Бесплатные приглашения (`amount_grosze = 0`) и неизвестные источники показывайте отдельно. Для рекламы, профиля Instagram, Telegram, email и партнёров используйте разные `utm_source`/`utm_medium`, для кампаний и размещений добавляйте `utm_campaign`/`utm_content`.
