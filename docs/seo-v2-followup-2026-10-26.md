# Правки после просмотра SEO-релиза

Решения владельца от 26 октября 2026 имеют приоритет над исходным ТЗ.

## Разовые выступления

Импровизационный вечер описывается событием конкретной даты. «Нога в ногу» 25 октября остаётся доступна в архиве; повторение того же выступления не обещается. Пустые постоянные страницы восьми шоу сняты из навигации и sitemap. Уже созданные `/shou/<slug>` постоянно перенаправляют на конкретные опубликованные события. `/shou` ведёт в афишу. Новое импровизационное выступление получит собственный URL и описание.

PLAY-BACK на Tickets перенаправляется прямо на `/events/shou-play-back`, с исходной датой 23 мая 2026. Ссылки курсов ведут к актуальной афише и архиву. В админке убран выбор постоянного шоу, прежние связи в базе сохранены без публичного использования.

## Перенаправления

Владелец явно подтвердил объединение дублей даже без исходной GSC-выгрузки. Основные правила RU, с соответствиями UK/PL:

| Старый адрес | Конечный адрес |
|---|---|
| Poet `/improvizatsiya-varshava` | Poet `/kursy/improv` |
| Poet `/akterskaya-maysternost-varshava` | Poet `/kursy/acting` |
| Poet `/kurs-dlya-nachinayushchih-varshava` | Poet `/akterskie-kursy-varshava` |
| Poet `/kuda-poyti-odnomu-varshava` | Tickets `/kuda-poyti-odnomu-varshava` |
| Tickets `/probnoe-zanyatie-varshava` | Poet `/probnoe-zanyatie-varshava` |
| Tickets `/sobytiya-v-varshave` | Tickets `/afisha-varshava` |
| Tickets `/kuda-shodit-v-varshave-vecherom` | Tickets `/dosug-v-varshave` |

Польская страница warsztaty остаётся самостоятельной, как требует исходное ТЗ. Все постоянные перенаправления сохраняют query-параметры, включая UTM. Старое пробное `/events/improvizatsiya-probnoe-zanyatie-varshave-2026-07-29` ведёт на хаб записи `/probnoe/improv`, без промежуточной страницы. Неизвестный URL выступления не подменяется другим выступлением.

## Содержание

Курсы сохраняют исходные вводные тексты, фотографии, программу и ход занятия. Заголовки уточняют Варшаву и русский язык. Общая стоимость убрана по просьбе владельца; остаётся оплата блоками 590 zł за четыре занятия и пробное 100 zł. Раздел о речи объясняет конкретные упражнения, без текста об отсутствии отдельного курса.

Хаб двух курсов и информационная страница пробного переписаны на трёх языках. Есть сравнение программ, условия для новичков, длительность два часа, подготовка к занятию и продолжение после пробного. Старые шаблонные отзывы и неподтверждённые обещания не используются. Расписание берётся из общей базы; три ближайшие даты открыты, остальные доступны через раскрываемый список.

На страницах театра и досуга обновлены title, description, H1, вводный текст и разделы. Сначала показаны реальные предстоящие даты и цены. Указаны разные площадки, различие спектакля и импровизации, ссылки на архив, пробное занятие и правила возврата. Контент адаптирован для RU/UK/PL.

P!MPRO получает отдельный законченный description, без обрезки части слова. 404 имеет локализованные заголовок, пояснение и ссылки на афишу и курсы. Проверка HTTP 26 октября: `http://popularpoet.pl/` отвечает 308 на HTTPS; HTTPS перенаправляет к www/ru.

## Даты sitemap

Используются дата фактической правки исходников и `updated_at` базы. Дата не заменяется текущим временем при каждом запросе. Дубли и снятые страницы `/shou/*` исключены. Опубликованные прошедшие события доступны через архив, будущие остаются в sitemap.

## Проверки и ограничения

Результаты проверки опубликованного релиза сохраняются в `.tmp`. Тесты маршрутизации проверяют старое пробное, межсайтовый переход на информационную страницу и отсутствие подмены неизвестного выступления. Google-отзывы и изменения GBP остаются вне выпуска: пользователь сообщил об отсутствии данных, API исчерпал квоту. PageSpeed API также вернул 429; целевой LCP пока не подтверждён.
